# SE Website Making Task — Submission Guide

## Project title

AI StudyMate — Smart Study Assistant

## Website description (copy into the form)

AI StudyMate is a responsive student productivity website built using HTML, CSS, and JavaScript. It helps students organize study tasks by subject, estimate focus time, set due dates, track completed work, and view progress summaries. It includes a short AIML basics quiz with answer explanations. The prototype saves tasks and theme preferences in browser local storage. This version is front-end only; a SQL database or trained AI model can be added as a future enhancement.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## How to demonstrate it

1. Open the Home page and scroll through the sections.
2. Add a task such as “Revise supervised learning” with subject “Machine Learning” and 25 minutes.
3. Add another task and mark one complete.
4. Show the All / To do / Completed filters.
5. Refresh the page and demonstrate that tasks remain.
6. Complete the AIML quiz and show the score.
7. Toggle dark mode and show the theme is remembered.
