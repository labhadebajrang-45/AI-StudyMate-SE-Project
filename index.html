ABOUT THE PROJECT

Built to make studying feel manageable.

AI StudyMate is a student-focused working prototype created for the SE Website Making Task. It demonstrates interactive task management, browser-based persistence, progress summaries, and a sample AIML quiz. The current version uses rule-based features; it does not claim to run a trained AI model.
